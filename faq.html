Frequently asked questions

Quick answers about the current Best Way Academy frontend demo.

Can I browse and open individual courses?

Yes. The catalog supports search, category filters and sorting. Every course opens its own detail view with learning outcomes and modules.

Do cart and wishlist items stay after refresh?

Yes. They are stored in your browser using localStorage, so they remain on the same device/browser until cleared.

Does checkout charge a real card?

No. The current website is frontend-only. Checkout simulates enrollment and never sends or stores card details.

What happens after checkout?

The selected courses are saved to My Learning in the browser and an enrollment success page is shown.

Is login connected to a database?

No. Login and signup are demo browser state only. Real secure authentication requires a backend and database.

Can this website run on basic Hostinger hosting?

Yes. It is plain HTML, CSS and JavaScript, so no Node.js or npm is needed on the server.

Can real payments and a backend be added later?

Yes. The frontend flow is structured so secure authentication, a database, course management and payment APIs can be added in a later phase.
